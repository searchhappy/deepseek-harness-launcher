┌─────────────────────────────────────────────────────────────┐
│  Windows NSIS 安装程序（立即可用 ✅）                        │
└─────────────────────────────────────────────────────────────┘

  cd main
  npm install
  npm run build:nsis          # 标准版
  npm run build:nsis-setup    # 智能安装版

  输出: dist-installer/ 和 dist-setup-installer/

┌─────────────────────────────────────────────────────────────┐
│  macOS DMG 安装程序                                          │
└─────────────────────────────────────────────────────────────┘

  1️⃣ 创建图标:
     https://cloudconvert.com/ico-to-icns
     上传 main/assets/icon.ico → 下载 icon.icns
     保存到 main/assets/icon.icns

  2️⃣ 构建 (在 macOS 上):
     cd main
     npm run build:mac          # 标准版
     npm run build:mac-setup    # 智能安装版

┌─────────────────────────────────────────────────────────────┐
