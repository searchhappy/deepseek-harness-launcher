# 创建开箱即用版本的步骤

## 📋 准备工作

### 步骤 1：下载 Node.js 便携版

访问 https://nodejs.org/dist/v20.18.1/node-v20.18.1-win-x64.zip
或运行：

```bash
# 创建运行时目录
mkdir -p main/runtime

# 下载 Node.js（使用 PowerShell）
cd main
powershell -Command "Invoke-WebRequest -Uri 'https://nodejs.org/dist/v20.18.1/node-v20.18.1-win-x64.zip' -OutFile 'node-portable.zip'"

# 解压
powershell -Command "Expand-Archive -Path 'node-portable.zip' -DestinationPath 'runtime' -Force"

# 重命名目录
mv runtime/node-v20.18.1-win-x64 runtime/node
rm node-portable.zip
```

### 步骤 2：安装 DeepSeek Harness 到运行时

```bash
cd main/runtime

# 使用便携版 Node.js 安装 DeepSeek Harness
node/npm install -g --prefix . @deepseek-ai/dsh

# 或者安装到本地
node/npm install @deepseek-ai/dsh
```

### 步骤 3：修改应用代码

需要修改 `main.js` 使用打包的 Node.js 而不是系统的。

### 步骤 4：更新 NSIS 配置

添加 runtime 目录到打包文件列表。
