## 📦 技术细节

### 开箱即用版包含什么

```
DeepSeekHarness-Bundled-Installer-1.0.0.exe (298MB)
├── Electron 应用 (~73MB)
├── Node.js 22.12.0 便携版 (~83MB)
├── DeepSeek Harness + 依赖 (~100MB)
└── NSIS 安装程序框架 (~42MB)
```

### 运行原理

1. 安装时，所有文件被解压到用户选择的目录
2. `runtime/node/` - Node.js 便携版
3. `runtime/node_modules/` - 预装的 DeepSeek Harness
4. `main-bundled.js` - 使用打包的 Node.js 运行

### 关键代码

```javascript
// main-bundled.js 自动使用打包的 Node.js
function getBundledNpxPath() {
  if (app.isPackaged) {
    return path.join(process.resourcesPath, 'runtime', 'node', 'npx.cmd');
  }
  return path.join(__dirname, 'runtime', 'node', 'npx.cmd');
}
```
