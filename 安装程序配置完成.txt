【方法 3】构建 macOS DMG 安装程序
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  步骤 1: 创建 macOS 图标
  ─────────────────────────

  【Windows 用户】:
    1. 访问 https://cloudconvert.com/ico-to-icns
    2. 上传 main/assets/icon.ico
    3. 下载转换后的 icon.icns
    4. 保存到 main/assets/icon.icns

  【macOS 用户】:
    cd main
    chmod +x create-mac-icon.sh
    ./create-mac-icon.sh

  步骤 2: 构建（必须在 macOS 上）
  ─────────────────────────

  cd main
  npm install
  npm run build:mac           # 标准版
  npm run build:mac-setup     # 智能安装版

  📦 输出:
    - DeepSeek Harness Launcher-1.0.0-x64.dmg (Intel)
    - DeepSeek Harness Launcher-1.0.0-arm64.dmg (Apple Silicon)

     最低: v16.0.0
     推荐: v18.x 或 v20.x
