# DeepSeek Harness Desktop Launcher

本项目为 DeepSeek Harness 提供了一个功能完整的桌面启动器应用。

## 快速开始

1. 前往 [Releases](https://github.com/searchhappy/deepseek-harness-launcher/releases) 下载最新版本
2. 选择适合你的版本：
   - `DeepSeekHarness-Portable.exe` - 标准版（需要 Node.js）
   - `DeepSeekHarness-Installer.exe` - 安装版（自动引导安装）
3. 双击运行，开始使用！

详细文档请查看 [README.md](README.md)

## 功能特点

- 🎨 现代化界面
- 🔧 智能端口管理
- 📊 实时日志显示
- 🖥️ 应用内窗口模式
- 🎓 新手引导安装
